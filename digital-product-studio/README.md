# Digital Product Studio by Sadé


## What It Does


An all-in-one digital product creation studio that uses specialized workflows to create digital planners, printables, e-books, KDP products, branding kits, social-media templates, educational resources, mockups, Etsy listing assets, product bundles, and complete ready-to-sell digital products.


The plugin contains 29 supplied specialist skills and one coordinator. The workflows create files using the tools available in the current Codex session. Image generation, Canva access, and PDF libraries are separate capabilities, not bundled services.


**Private local plugin:** supplied mockup and listing references remain internal. Do not publish or share this complete source package without checking redistribution rights. Generated customer products must exclude source reference libraries, previews, indices, excluded files, and skill instructions.

## Complete Product Workflows


**Digital planner:** Idea → Tab Shape Selection → Planner Creation → artwork/count/date QC → Hyperlinking when requested → final link coverage and render QA → Mockups → Etsy Listing Images → Listing Copy → Etsy delivery package.

**KDP product:** Concept → specialized children’s/coloring/puzzle/low-content creator → missing interior work and print QA as applicable → companion-product bundle only if requested → requested listing assets and packaging.

**Branding product:** Brand Strategy → Branding Kit → coordinated Social Templates → YouTube Branding when requested.

**Seasonal collection:** Seasonal bundle owner → only required specialist production → shared package. **Product expansion:** Factory → ledger comparison → distinct requested products → ledger update. Ideas-only requests remain ideas-only.


## Direct Skill Usage


Ask for the specific result or invoke a specialist such as `$create-product-listing`. In a fresh task, use the skill picker to select the installed plugin skill if another installed skill has the same name. Single-purpose requests do not require a complete factory workflow.


## Adding New Skills


1. Add `skills/<unique-hyphenated-name>/SKILL.md` with YAML `name` and `description` frontmatter. Keep scripts, references, templates, assets, and `agents/openai.yaml` inside that folder.
2. Give the description a precise activation scope; use relative paths.
3. Add a catalog entry to `docs/skill-catalog.json`, document it here, and add a routing link only if coordination needs it. No manifest change is needed: `skills` already points to `./skills/`.
4. Run the official skill and plugin validators plus the local integrity script. Update the source inventory only when intentionally importing a new source version.
5. Reinstall after the cachebuster update and open a fresh task. Future Notion, website, invitation, wedding, resume, business-document, sticker, SVG, POD, course, presentation, and travel-planner skills use this same structure.

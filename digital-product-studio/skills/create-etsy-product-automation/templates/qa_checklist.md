# Final Quality-Assurance Checklist

## Product

- [ ] Exact requested page or asset count completed.
- [ ] Every page is delivered separately.
- [ ] No page is a collage or contact sheet.
- [ ] No placeholders remain.
- [ ] No duplicate filler pages are counted as unique.
- [ ] Dimensions and orientation are correct.
- [ ] Full-page designs fill the complete canvas.
- [ ] Text is legible and proofread.
- [ ] Character and brand consistency are preserved.

## Files

- [ ] File names are clear and numbered.
- [ ] PDF is in the correct order.
- [ ] PDF opens successfully.
- [ ] Hyperlinks work when required.
- [ ] Editable-link instructions are accurate.
- [ ] ZIP opens and contains every required folder.

## Etsy Listing

- [ ] Title accurately describes the product.
- [ ] Description matches the actual deliverables.
- [ ] Digital-download statement is included.
- [ ] No-physical-item statement is included.
- [ ] File formats and dimensions are accurate.
- [ ] License terms are accurate.
- [ ] Listing images are readable and not overcrowded.
- [ ] Mockups do not misrepresent the product.
- [ ] Customer-facing files do not mention the internal skill.

## Correction Rule

When one item fails, correct only that item whenever possible. Preserve all approved work and rerun the relevant checks.

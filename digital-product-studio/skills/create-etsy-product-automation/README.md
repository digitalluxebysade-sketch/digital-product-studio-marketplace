# Digital Luxe Etsy Product Automation Skill

## What it does

This installable automation turns one prompt into a complete Etsy-ready digital-product package. It can create the actual product, separate page files, compiled PDFs, listing images, mockups, SEO listing copy, customer instructions, licensing, and a final organized ZIP.

## Install

1. Download the ZIP.
2. Open the area in ChatGPT Work that supports custom skills.
3. Upload or import the ZIP.
4. Start a new task and reference `create-etsy-product-automation`, or describe the Etsy product you want created.

## Suggested first prompt

“Use create-etsy-product-automation to create a complete Etsy digital product for [target customer]. The product should be a [product type] with [page or asset count], in a [theme] style. Create every page separately, compile the final PDF, create five listing images, three mockups, Etsy listing copy, customer instructions, license terms, and a final organized ZIP.”

## Important

This package contains an automation workflow. It does not include access to paid third-party tools, marketplace fees, or guaranteed sales.

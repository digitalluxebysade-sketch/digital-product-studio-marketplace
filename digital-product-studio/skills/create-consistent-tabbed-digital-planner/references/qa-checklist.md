# Digital Planner Quality Checklist

## Canvas

- [ ] Every image uses the exact requested width and height.
- [ ] The cream or white worksheet fills 100% of the canvas edge to edge.
- [ ] The full-canvas page base continues underneath every tab and navigation element to the outer canvas pixels.
- [ ] Left and bottom exterior spacing are exactly 0%.
- [ ] No dark, plaid, black, colored, or photographic background surrounds the worksheet.
- [ ] No backing board, mat, exterior frame area, mockup, floating paper, or page drop shadow appears.
- [ ] No rounded outer corner reveals another layer.
- [ ] No tab appears to extend from a smaller sheet onto an exposed backing surface.
- [ ] Right tabs use no more than 6% of canvas width.
- [ ] Top navigation uses no more than 7% of canvas height.
- [ ] No page is accidentally cropped.
- [ ] Orientation is correct.
- [ ] Tabs remain inside the page boundary.
- [ ] Tabs remain inside the device screen on mockups.

## Cover

- [ ] Title is spelled correctly.
- [ ] No accidental extra text appears.
- [ ] Main title is readable.
- [ ] Cover matches the interior.
- [ ] Artwork is original.
- [ ] Composition is not crowded.

## Tab lock

- [ ] Same number of tabs on every tabbed page.
- [ ] Same labels.
- [ ] Same order.
- [ ] Same size.
- [ ] Same placement.
- [ ] Same spacing.
- [ ] Same colors.
- [ ] Same font.
- [ ] Same text orientation.
- [ ] Same border and shadow.
- [ ] Correct active tab.
- [ ] No tab is missing, duplicated, clipped, or malformed.

## Interior

- [ ] The exact requested number of separate finished pages exists.
- [ ] Every manifest row has one full-size, full-canvas page file.
- [ ] Every page has a unique title, purpose, and useful page-specific content.
- [ ] Every page contains appropriate tables, lines, calendars, trackers, checklists, grids, or prompts.
- [ ] No customer design work is required before use.
- [ ] Page type matches its filename.
- [ ] Writing areas are spacious.
- [ ] Text is readable.
- [ ] Section labels are spelled correctly.
- [ ] Decorative elements do not block writing areas.
- [ ] Margins are consistent.
- [ ] Palette and typography match the master style.
- [ ] Recurring headers and footers are consistent.

## Calendars

- [ ] Month name is correct.
- [ ] Year is correct.
- [ ] Weekday order is correct.
- [ ] Number of days is correct.
- [ ] Dates align with weekdays.
- [ ] No duplicate or missing dates.

## Handoff

- [ ] Completion tracker reached Page N of N.
- [ ] Blank shell is excluded unless specifically requested as an extra.
- [ ] No navigation-only page, empty sheet, decorative background, mockup, duplicate-only page, or collage was counted.
- [ ] Files are numbered in sequence.
- [ ] Page inventory matches delivered files.
- [ ] Failed pages were regenerated from the master shell.
- [ ] Hyperlink status is stated accurately.
- [ ] Hyperlink map is included when requested.
- [ ] PDF order matches the page inventory.
- [ ] PDF was assembled only after all separate pages passed QA.
- [ ] Separate page files remain available alongside the PDF.
- [ ] Listing images use the correct dimensions.

# Create Canva Interactive Birthday Invitations

Create a complete, polished, mobile birthday invitation website design that the user can assemble and hyperlink in Canva.

## Non-negotiable rule: Canva only, no coding

Never generate or recommend HTML, CSS, JavaScript, React, source code, a coded website, or a developer handoff.

Do not create a functional form, live countdown, embedded map, audio player, database, or calendar integration. Instead, create the matching visual sections and give simple Canva instructions for adding clickable links, buttons, video, music, directions, and RSVP destinations.

Use ChatGPT image generation for the original invitation visuals whenever image generation is available.

## Use this skill for requests such as

- “Create an interactive birthday invitation website in Canva.”
- “Make a scrolling birthday invitation section by section.”
- “Turn this birthday theme into a Canva website invite.”
- “Create a mobile invitation with RSVP, countdown, directions, music, and gallery sections.”
- “Make a birthday website invitation template I can sell.”
- “Use this video as structural inspiration for my invitation.”

Do not use this skill when the user wants only one flat invitation card unless they also want a website-style invitation or coordinated product bundle.

## Default outcome

Create the most complete visual package possible from the information available:

1. A concise creative brief.
2. A six-color style system with HEX codes.
3. A coordinated section plan.
4. A mandatory closed-envelope opening image.
5. A mandatory matching opened-envelope reveal image.
6. Separate mobile website-section images.
7. Matching transparent decorative assets.
8. Canva-only assembly and hyperlink guidance.
9. Optional product-listing images, mockups, and sales copy.

Do not stop at a generic prompt list when the user asked to create the invitation. Generate the visual sections in sequence.

# Workflow

## Phase 1 — Analyze the request and reference

When a reference image, PDF, or video is supplied:

1. Identify its useful structural ideas, such as section order, pacing, hierarchy, decorative density, phone presentation, and transitions.
2. Do not copy names, logos, watermarks, copyrighted characters, exact artwork, or distinctive compositions.
3. Build an original invitation using the requested theme and information.
4. Preserve user-supplied photos or artwork exactly when requested; do not redraw, recolor, crop important details, or invent replacements.
5. Create a short creative brief before image generation to lock the direction.
6. Lock the customer's requested dimensions, unit, orientation, and aspect ratio before generating the first section.

## Phase 2 — Create the master style system

Define and keep consistent:

- Six-color palette with HEX values
- Headline font direction
- Script or accent font direction
- Body font direction
- Decorative motifs
- Border and frame style
- Button style
- Background treatment
- Photo treatment
- Spacing and section-divider rules

Recommend Canva-available fonts when practical, but do not claim a font is available without checking. The generated images should communicate the font style even when the final editable text will be added in Canva.

## Phase 3 — Plan the website sections

Default section order:

1. Closed envelope
2. Opened envelope reveal
3. Hero cover
4. Welcome message
5. Event details
6. Countdown
7. Dress code and guest notes
8. Schedule or itinerary
9. Venue and directions
10. RSVP
11. Photo gallery
12. Gift registry or gift note
13. Music or playlist
14. Closing and social hashtag

### Mandatory opening: two-image envelope reveal

Always create two separate opening images before the hero cover, even when the user does not repeat this requirement:

1. **Closed envelope:** Show a complete closed envelope as the main focus, styled to the invitation theme. Use an appropriate seal, ribbon, bow, monogram, floral cluster, or small themed detail. Keep it front-facing or at a clear three-quarter angle and leave enough surrounding space for Canva animation.
2. **Opened envelope:** Show the exact same envelope in the exact same position, scale, camera angle, lighting, palette, materials, decorations, and background, but with the flap open and an invitation card visibly emerging or revealed. The card may preview the celebrant name, monogram, age, or short invitation heading.

Treat these images as a continuity pair, not two independent designs. Generate the closed image first, approve or lock it, then use it as the visual reference for the opened image. Change only the envelope state and the revealed card. Do not change the envelope color, seal, bow, flowers, shadows, perspective, crop, background, or decorative placement between the two images.

Do not replace the pair with a single envelope icon, a static RSVP envelope, one image that shows both states, a contact sheet, a storyboard, or an interior page. Do not begin with the hero cover. The closed envelope must be the first visible invitation image, and the opened envelope must be the second.

Remove sections the user does not need. Combine sections only when doing so will not crowd the page.

For every section, specify:

- Purpose
- Main headline
- Suggested short copy
- Visual focus
- Required placeholder area
- Canva interaction to add later, when applicable

## Phase 4 — Generate each section separately

Generate each website section as its own image. Do not create the entire scrolling website as one giant image unless the user explicitly requests that format.

### Consistency requirements

Every section must maintain the same:

- Color palette
- Lighting
- Illustration or photography style
- Decorative motifs
- Borders and frames
- Typography direction
- Button appearance
- Spacing rhythm
- Level of detail

### Image requirements

- Use the customer's requested width, height, unit, orientation, and aspect ratio.
- Keep the same approved size across every website section unless the customer explicitly requests mixed dimensions.
- When an exact unusual size is not directly supported by image generation, preserve the requested aspect ratio and prepare the artwork for exact placement in a custom-size Canva canvas.
- Never crop, stretch, or distort artwork merely to force it into the requested dimensions.
- Keep important text and decorations inside generous safe margins.
- Do not overcrowd the design.
- Keep copy short enough to read on a phone.
- Leave clean space where the user may add editable Canva text.
- Avoid embedding long addresses, URLs, complex schedules, or form fields into generated artwork.
- Use simple, correctly spelled headings when text is necessary.
- Generate one section at a time so corrections do not affect the entire invitation.

For the two opening images, preserve pixel-level composition as closely as image generation permits. Use the completed closed-envelope image as the required image reference for the opened-envelope edit. Prefer editing that image to open the flap and reveal the card instead of regenerating the entire scene from text.

4. Upload and arrange the remaining generated sections after the envelope pair.
5. Add editable text over blank or lightly decorated text areas.
6. Add clickable buttons using Canva links.
7. Link RSVP buttons to Google Forms, Tally, Jotform, Typeform, email, text, or another user-supplied destination.

9. Link gift and playlist buttons to the user-supplied pages.
10. Create a visual countdown section using static number placeholders, or add a Canva-supported countdown/video element if available to the user.
11. Add gallery photos in Canva frames.
12. Preview the design on mobile and publish it as a Canva Website.

Never claim the countdown is live or the form is functional unless the user actually added a supported Canva element or external link.

## Image-Generation Usage Efficiency Protocol

Apply this protocol whenever this skill creates, edits, regenerates, enhances, or reviews generated images.

### Minimum-generation rule

- Use the fewest image-generation calls necessary to complete the request correctly.
- Generate exactly the number of images requested or explicitly required by this skill's current deliverable.
- Do not automatically create alternate versions, bonuses, extra colorways, tests, mockups, transparent assets, listing images, or decorative extras unless the user requests them or they are an explicit required output.
- Do not use a tool's maximum image allowance merely because it is available.

### Validation-before-batch rule

- When a coordinated visual system has not been approved, create one representative validation image before a multi-image batch.
- Validate dimensions and aspect ratio, canvas coverage, composition, background treatment, typography placement, character appearance, palette, borders, tabs, panels, margins, decorative density, and functional areas.
- Do not generate a large batch from an unverified composition.
- If the user explicitly requests the entire batch immediately, proceed without requesting another approval message; internally validate the composition before starting the batch.

### Approved-design locking rule

After approval, lock the canvas dimensions, grid, layout, background, margins, heading placement, typography hierarchy, character identity, skin tone, facial features, hairstyle, clothing, illustration style, planner tabs, border thickness, palette, decorative style, spacing, and product-cover proportions. Change only content that must differ. Do not redesign each image independently.

### Targeted-correction rule

- Modify only the affected image and specified elements.
- Preserve everything that already passes.
- Do not regenerate a complete batch because one image fails.
- Prefer a targeted edit over restarting a nearly correct image.
- Correct only the title for a misspelling, only the tab for a moved tab, only the canvas composition for an exposed planner background, and only the changed character for identity drift.

### One-quality-control-pass rule

Perform one structured quality-control pass against explicit requirements. Correct only clear failures. Do not repeatedly regenerate acceptable images for subjective perfection. Stop generating after all explicit checks pass.

### Full-canvas composition rule

For planner pages, worksheets, printables, invitations, covers, activity pages, workbook pages, and similar full-page designs:

- Treat the design canvas and functional page as the same object.
- Start the intended page background at x=0 and y=0 and extend it to the final right and bottom edges.
- Fill the complete requested canvas.
- Never place a smaller page over an exterior background.
- Do not show a desktop, room, table, fabric, plaid surface, backing board, mat, frame, device, paper stack, or mockup unless explicitly requested.
- Do not add unrequested outer margins or borders.
- Use decorative patterns only inside intentional design areas permitted by the user.

### Transparent-asset rule

When transparency is requested, use a genuinely transparent background—not white, cream, gray, colored, or checkered. Keep the complete asset visible, do not crop important parts, and add no shadow or outline unless requested.

### Reference-image role rule

- Assign each reference a role before generating: composition, character, color, theme, typography, product-preservation, or sequence/animation.
- Use each reference only for its assigned purpose; do not copy unrelated content from a composition reference.
- Preserve any referenced character, product cover, logo, planner layout, or illustration that the user requires to remain exact.

### Text-accuracy rule

- Use only user-supplied or explicitly required text. Do not invent names, dates, prices, addresses, schedules, appointments, product details, labels, or sample entries.
- Proofread visible text before finalizing.
- Prevent misspellings, clipping, warping, duplicate headings, unreadable lettering, overlaps, placeholder text, random symbols, and unrequested handwritten entries.
- Keep blank templates free of sample writing, appointments, stickers, checklist entries, and example content unless requested.

### Batch-consistency rule

Establish one master visual system for coordinated sets. Keep dimensions, orientation, background, margins, headers, footers, font hierarchy, tabs, borders, line weight, character design, illustration style, decorative density, palette, spacing, and functional layout consistent. Change only the required title, content, date, month, activity, or functional fields.

### Processing-efficiency rule

Do not use image generation for text-only work such as descriptions, page lists, section planning, filenames, prompts, instructions, content organization, marketing copy, proofreading before layout, or assembly explanations. Do not inspect unrelated applications, repositories, files, tools, or connected services.

### Controlled-completion rule

Stop after the requested image count is complete, dimensions are correct, the approved system is preserved, one quality-control pass is complete, clear failures are corrected, and requested files are delivered. Do not automatically begin PDF assembly, hyperlinking, Canva setup, animation, listing creation, marketing copy, or social promotion unless requested or explicitly required by this skill's current function.

## Efficient Envelope-Opening Sequence

When the invitation includes an envelope opening:

1. Generate the closed envelope as the first section.
2. Generate the same envelope opened as the next section.
3. Preserve the envelope design, paper, wax seal, colors, lighting, and decorative elements.
4. Make the opened state a direct continuation of the closed state, not a redesign.
5. Do not generate envelope alternatives unless requested.
6. Generate every section at the customer's requested dimensions.
7. Do not code unless this skill is explicitly being used for a coding request.

Do not reinterpret or redesign an established character between images. Change expressions and poses only when requested while preserving identity.

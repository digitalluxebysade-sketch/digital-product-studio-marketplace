# Page Type Library

Use these as flexible building blocks. The user may request any combination, and the final manifest must still equal the exact page count.

## Front matter

- Cover
- Title page
- Copyright and disclaimer
- Dedication
- Welcome note
- Table of contents
- About the author or brand
- How to use this e-book

## Educational content

- Chapter opener
- Single-column lesson
- Two-column lesson
- Steps or process page
- Tips page
- Mistakes to avoid
- Myth versus fact
- Case study
- Example breakdown
- FAQ
- Resource page
- Key takeaways

## Visual content

- Pull-quote page
- Diagram
- Timeline
- Comparison page
- Icon grid
- Before-and-after framework
- Photo-led editorial page
- Data or statistics page with cited source

## Interactive content

- Worksheet
- Checklist
- Tracker
- Reflection prompts
- Journal page
- Action plan
- Goal-setting page
- Planning template
- Fillable form layout

## Closing content

- Chapter recap
- Final action plan
- Conclusion
- Next steps
- Call to action
- References or endnotes
- Thank-you page
- Back cover

## Density guidance

- Cover: minimal text.
- Chapter opener: low to medium density.
- Article page: medium density with readable paragraphs.
- Worksheet: 60–75% functional writing space.
- Checklist: enough spacing for marks and notes.
- Quote page: one primary statement plus small supporting text.
- Infographic: simplify the message rather than shrinking labels.

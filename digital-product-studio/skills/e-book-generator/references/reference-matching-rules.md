# Reference Matching Rules

Use this guide whenever the user uploads an e-book, PDF, screenshot, image set, ZIP, mood board, or template as visual inspiration.

## Match these design properties

- overall page proportions and orientation
- visual hierarchy
- approximate whitespace ratio
- alignment and grid logic
- one-column versus multi-column structure
- title placement and scale
- use of rules, borders, frames, labels, and page numbers
- photography or illustration treatment
- decorative density
- recurring header/footer system
- chapter opener rhythm
- balance between text and images

## Do not copy these properties directly

- original wording or paragraphs
- photographs or illustrations that are not licensed for reuse
- logos, trademarks, watermarks, URLs, social handles, or author names
- unique branded characters
- a template's exact arrangement when it is so distinctive that the result becomes a near-duplicate

## Translation method

Turn the reference into abstract design instructions. Example:

> Warm ivory background, charcoal typography, elegant high-contrast serif display font, clean sans-serif body font, 10% outer margins, thin rules, rectangular editorial photography, quiet footer, and alternating one- and two-column layouts.

Then apply that design system to the user's new content. Preserve the feeling and quality level while creating an original product.

## User overrides

The user's latest instruction always overrides the reference. For example, a user may provide a neutral reference but request a pink palette, landscape orientation, no photos, or a larger body font. Keep the reference's structural logic while applying the requested changes.

# E-Book Generator Quick Start

Invoke the skill with `@e-book-generator` or select **E-Book Generator** from your Skills.

## Complete prompt template

```text
Create a [NUMBER]-page e-book about [TOPIC] for [AUDIENCE].

Title: [TITLE OR “CREATE ONE”]
Page size: [DIMENSIONS OR “USE DEFAULT”]
Orientation: [PORTRAIT/LANDSCAPE]
Theme: [AESTHETIC, COLORS, MOOD]
Writing tone: [TONE]
Reference: [UPLOAD OR DESCRIPTION]
Include: [COVER, CONTENTS, CHAPTERS, WORKSHEETS, CHECKLISTS, ETC.]
Author/brand: [NAME]
Final formats: [PNG PAGES, PDF, ZIP]

Generate every page separately, keep the layout consistent, proofread all text, and complete the exact requested page count.
```

## Reference-style example

```text
Use @e-book-generator to create a 35-page beginner guide about starting a candle business. Use the uploaded reference for the layout and formatting, but change the palette to cream, cocoa brown, and muted pink. Include a cover, contents page, introduction, five chapters, three checklists, two worksheets, an about-the-author page, a conclusion, and a back cover. Create every page separately and compile the finished PDF.
```

## Fully custom example

```text
Use @e-book-generator to create a 24-page landscape e-book called “The Content Reset.” Make it bold, modern, black, white, and electric blue with oversized typography, geometric shapes, and no photography. Write for beginner beauty creators. Include action steps, examples, a content calendar, a hook bank, and a final 30-day plan.
```

## Neutral minimalist example

```text
Use @e-book-generator to create a 40-page personal-finance basics guide for young women. Use a warm ivory minimalist editorial theme with elegant serif headlines, clean sans-serif body text, thin rules, lifestyle photography, one- and two-column layouts, and a quiet footer system. Use original writing and cite authoritative sources for financial facts.
```

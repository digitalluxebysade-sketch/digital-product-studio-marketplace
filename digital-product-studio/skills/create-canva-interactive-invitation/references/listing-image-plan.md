# Five Product-Listing Images

Create five separate listing graphics for a sellable invitation template or invitation automation product. Keep the invitation itself as the hero and avoid overcrowding.

## Listing Image 1 — Hero
- Product name
- Strong invitation preview
- Clear event type or customizable positioning
- Minimal supporting copy

## Listing Image 2 — What Is Included
- Show representative separate sections
- Mention the closed and opened envelope when included
- Mention Canva-ready sections, transparent assets, or listing images only when actually included
- Do not show all pages in a tiny unreadable grid

## Listing Image 3 — How It Works
Use a simple three-step visual:
1. Download or receive the files
2. Edit and assemble in Canva
3. Share the finished invitation

Adapt the wording if the product workflow differs.

## Listing Image 4 — Customization
Highlight editable names, event details, colors, photos, links, buttons, and sections. Do not claim that an element is editable unless the product actually supports it.

## Listing Image 5 — Use Cases or Benefits
Show several suitable event types or benefits, such as:
- Any event type
- Mobile-friendly sharing
- Coordinated design system
- Reusable Canva workflow
- No coding required

Do not put a character on every listing image. Use one character image at most when the theme includes a character, unless the user explicitly requests more.

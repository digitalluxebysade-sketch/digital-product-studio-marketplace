# Create Canva Interactive Invitation Skill

Version 1.1.0

This skill expands the interactive birthday invitation workflow into a flexible invitation creator for virtually any event. It creates Canva-ready graphics with ChatGPT image generation and does not code the invitation.

## Main features

- Any event type
- Customer-selected dimensions
- Interactive closed/open envelope reveal
- Adaptive event-specific section planning
- Every section generated separately
- Up to 10 separate images per supported batch
- Consistent visual system across all sections
- Connected-page flow so one section visually continues into the next for interactive Canva invitations
- Optional transparent assets
- Optional five-image product-listing set
- Targeted corrections without regenerating approved work

## Install

Upload the ZIP from ChatGPT's Skills page using Create > Upload from your computer. After installation, invoke it by name or ask ChatGPT to create an invitation that matches the skill description.

## Included files

- `SKILL.md` — core workflow
- `references/invitation-playbooks.md` — section plans by event type
- `references/section-library.md` — adaptive section definitions
- `references/listing-image-plan.md` — five listing-image plan
- `assets/STARTER-PROMPT.md` — reusable customer prompt

# Starter Prompt

Use the `create-canva-interactive-invitation` skill to create a [EVENT TYPE] invitation for Canva.

Size: [WIDTH × HEIGHT PX]
Theme: [COLORS, MOOD, STYLE]
Event name or honoree: [NAME]
Date and time: [DETAILS]
Location: [VENUE AND ADDRESS]
RSVP: [METHOD AND DEADLINE]
Required sections: [LIST]
Transparent assets: [YES/NO + ASSET LIST]
Product-listing images: [YES/NO]
References: [ATTACH IMAGES OR VIDEO]

Generate every section as its own separate image. Use ChatGPT image generation for all original visuals. Do not code. Keep the set consistent and uncluttered, and continue in batches until every requested section is complete. For interactive invitations, make the pages connect visually at the cut-off edges so the design flows from one page to the next like one continuous scene.

# Example prompts and trigger boundaries

## Good prompts
- @editable-ebook-workbook-creator Create an editable ebook and matching workbook about [topic] for [audience], with practical templates and sales-page copy.
- Use this skill to create an original commercial-ready product, show the manifest first, and deliver every final asset separately.
- Use my uploaded images only as aesthetic references; do not copy their exact designs.

## Do not trigger for
- A simple definition or brainstorming list with no request to build the product.
- A request to copy, trace, or recreate a third-party marketplace product exactly.
- A request outside the skill's stated product type.

## Delivery checklist
- Approved numbered manifest
- Correct dimensions and orientation
- Separate final assets
- Consistent visual system
- Proofread text and repeated details
- Honest editable/source-file wording
- Buyer instructions and file manifest when requested
- Listing copy and preview only when relevant

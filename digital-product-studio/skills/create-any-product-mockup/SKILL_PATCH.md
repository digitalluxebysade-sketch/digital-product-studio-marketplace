# Skill Patch: Pinterest-Ready Reference-Driven Mockups

Merge this section into the existing `create-any-product-mockup` skill.

## Core objective

Create Pinterest-ready aesthetic mockups that combine product accuracy with curated scene, styling, mood, lighting, composition, and commercial clarity.

## Backend library requirement

Before every generation, load `reference-index.json`, retrieve 2-5 active matching reference images, and use those images as actual visual inputs whenever supported. Never load the full library. Never use inactive, duplicate, or interface references.

## Silent mockup blueprint

Build this blueprint before generating:

- Product category and exact construction
- Blank, design-applied, or fully created mode
- Audience and model presentation
- Aesthetic direction
- Scene/environment
- Lighting and mood
- Color palette
- Pose and framing
- Props and accessories
- Design-placement zone and print method
- Output dimensions and number of separate images
- Selected reference IDs and assigned roles

## Reference blending

Use each reference only for its assigned role. For example:

- REF A: garment construction
- REF B: model pose and framing
- REF C: scene and lighting
- REF D: palette and prop styling

Create an original result rather than copying any complete source image.

## Pinterest and Etsy standard

Every result must be save-worthy and sellable: clean framing, strong subject emphasis, coordinated palette, soft intentional lighting, realistic materials, and enough product visibility for an Etsy listing.

## Copyright and identity protection

Do not reproduce visible logos, copyrighted characters, branded graphics, marketplace labels, watermarks, or exact text from references. Do not recreate a real reference person's exact face or identity.

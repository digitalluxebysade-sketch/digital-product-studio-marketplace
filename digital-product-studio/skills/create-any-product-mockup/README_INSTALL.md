# Create Any Product Mockup — Updated Skill v3.0.1

This package is a merged install/update ZIP for ChatGPT Work.

## What is included
- `SKILL.md` — full updated mockup skill instructions
- `manifest.json` — package metadata
- `PROJECT_INSTRUCTIONS.txt` — recommended Project-level instructions
- `BACKEND_REFERENCE_RULES.md` — backend selection and safety rules
- `reference-index.json` and `reference-index.csv` — searchable reference index
- `reference_library/` — curated private image backend
- `previews/` — category preview sheets
- `examples/retrieval_examples.json` — retrieval examples

## Main upgrades
- Pinterest-ready aesthetic mockup rule
- Scene and mood preservation
- Pose and framing support
- 2–5 reference retrieval rule
- Product construction awareness
- Better quality control
- Separate image generation rule

## Install / update steps
1. Upload this ZIP in ChatGPT Work where you manage skills.
2. Use `SKILL.md` as the primary skill instructions.
3. Keep the `reference-index.json` beside the `reference_library` folder.
4. Add `PROJECT_INSTRUCTIONS.txt` to your Project instructions if you are using a Project.
5. Keep this package private.

## Important
This package includes private inspiration references for backend guidance. Do not include the reference images in a customer-facing product unless you own them or have permission to redistribute them.

# Output Packaging Standard

## Product folder structure

Use a clear structure such as:

```text
PRODUCT-ID_Product-Name/
├── 01_Final_Product/
│   ├── PDF/
│   ├── Individual_Pages/
│   ├── Hyperlinked/
│   └── Editable_or_Template_Instructions/
├── 02_Covers/
├── 03_Bonus_Assets/
├── 04_Customer_Instructions/
├── 05_License/
├── 06_Listing_Materials/
│   ├── Listing_Images/
│   ├── Mockups/
│   ├── Product_Copy/
│   └── Social_Promotion/
└── PRODUCT_LEDGER.csv
```

Only create folders that contain promised files.

## File naming

Use predictable names:

- `PRODUCT-ID_001_Cover.png`
- `PRODUCT-ID_002_Dashboard.png`
- `PRODUCT-ID_003_Monthly-Planner.png`
- `PRODUCT-ID_Full-Product.pdf`
- `PRODUCT-ID_Hyperlinked.pdf`
- `PRODUCT-ID_Customer-Instructions.pdf`
- `PRODUCT-ID_License.txt`
- `PRODUCT-ID_Listing-Image-01.png`

Use zero-padded numbers so files sort correctly.

## ZIP verification

Before delivery:

1. Remove hidden temporary files and duplicate previews.
2. Confirm the ZIP has a single clearly named product folder when appropriate.
3. Open the ZIP and list its contents.
4. Verify every promised file exists.
5. Verify the final archive size is reasonable.
6. Provide a direct download link.

# Quality Control Checklist

Run this once after all required outputs are present. Correct only failed items.

## Manifest

- [ ] Every promised product exists.
- [ ] Every promised page exists.
- [ ] Every promised asset exists.
- [ ] Counts match the request exactly.
- [ ] Covers and interior pages are counted correctly.

## Dimensions and composition

- [ ] Dimensions and orientation match the manifest.
- [ ] Functional pages fill the full canvas.
- [ ] No unintended exterior background, frame, desk scene, mat, shadow, black bar, or side margin appears.
- [ ] Navigation and tabs remain inside the canvas.
- [ ] No important content is clipped.

## Separate outputs

- [ ] Every finished page is a separate file or image output.
- [ ] No collage or contact sheet is being substituted for separate pages.
- [ ] Batch labels and page numbers match the manifest.

## Visual consistency

- [ ] Colors remain consistent.
- [ ] Typography hierarchy remains consistent.
- [ ] Repeating elements remain in the same position.
- [ ] Tabs and navigation remain unchanged where required.
- [ ] Approved character features remain locked.
- [ ] Decorative density is balanced and not overcrowded.

## Text and functionality

- [ ] Titles, headings, labels, dates, months, and numbers are spelled correctly.
- [ ] No random filler text appears.
- [ ] Writing areas are usable.
- [ ] Forms, checkboxes, lines, and fields align correctly.
- [ ] Hyperlinks work when promised.

## Originality and claims

- [ ] References were used for direction, not copied.
- [ ] The product has a distinct customer purpose.
- [ ] Listing claims match the actual files.
- [ ] License terms match what is delivered.

## File verification

- [ ] PDFs open successfully.
- [ ] Images open successfully.
- [ ] Transparent assets have transparency.
- [ ] ZIP opens successfully.
- [ ] Folder names and filenames are clear.
- [ ] No temporary or duplicate files remain.
- [ ] The product ledger is updated.

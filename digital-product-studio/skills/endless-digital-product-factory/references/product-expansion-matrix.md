# Product Expansion Matrix

**Open-category rule:** This matrix supplies optional inspiration only. It never limits what may be created. When the user requests a product type, niche, audience, format, style, or function not listed here, use the user's request and add the needed custom values.

Use this reference to create distinct, strategically useful product concepts. Do not select random combinations that lack a believable customer need.

## Distinctness test

Before approving a concept, answer:

1. Who is it for?
2. What specific problem does it solve?
3. What outcome does it create?
4. Why is this format suitable?
5. How is it meaningfully different from existing ledger entries?
6. Is it an intentional companion or an accidental duplicate?

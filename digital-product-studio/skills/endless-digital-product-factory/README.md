# Endless Digital Product Factory v1.1.0

This is an instruction-only OpenAI Agent Skill for creating any lawful digital product the user requests, including custom, uncommon, hybrid, or newly invented product types. It also creates product families, collections, bundles, listing materials, and continuation workflows without repeating previously created concepts. All product lists are examples, not restrictions.

## Install in ChatGPT

1. Open ChatGPT.
2. Select your profile icon.
3. Select **Skills**.
4. Select **Create**.
5. Select **Upload from your computer**.
6. Upload the ZIP file containing this folder.
7. Review the skill and install it.

## Suggested invocation

- `Use @endless-digital-product-factory to turn this niche into a complete 5-product collection.`
- `Use @endless-digital-product-factory to create the next product in my ledger without repeating anything.`
- `Use @endless-digital-product-factory to turn this one planner idea into a full product family.`
- `Use @endless-digital-product-factory to create this custom digital product exactly as described, even if it is not listed in the skill examples.`

## Included files

- `SKILL.md` — main workflow and rules
- `references/product-expansion-matrix.md` — idea-generation framework
- `references/quality-control-checklist.md` — final validation
- `references/output-packaging.md` — delivery structure
- `assets/product-ledger-template.csv` — duplicate-prevention ledger
- `assets/product-brief-template.md` — product specification template

No scripts or external network actions are included.

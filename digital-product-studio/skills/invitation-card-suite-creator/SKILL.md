# Invitation Card Suite Creator

Create a polished stationery suite with consistent typography, motifs, spacing, and event details across every piece.

## Inputs to resolve
- Event type, honoree or couple, date, time, venue, address, host, RSVP, and deadline
- Theme, palette, formality, and print/digital use
- Single card or full suite
- Required sizes, bleed, and editable format
- Whether photographs, illustrations, maps, registry information, or QR codes are needed

## Default 10-asset suite
1. Main invitation front - 5 x 7 inches
2. Main invitation back - 5 x 7 inches
3. Details card - 4 x 6 inches
4. RSVP card - 3.5 x 5 inches
5. Save-the-date card - 5 x 7 inches
6. Thank-you card - 5 x 7 inches
7. Envelope liner or envelope-front concept
8. Mobile invitation - 1080 x 1920 px
9. Social announcement - 1080 x 1080 px
10. Separate listing-preview mockup

## Workflow
1. Collect or clearly label all final event details. Do not invent realistic contact details or addresses unless the design is explicitly a sample.
2. Define a locked invitation style and numbered asset manifest.
3. Use 0.125-inch bleed and a safe text margin for print pieces unless the printer specifies otherwise.
4. Generate the front, back, inserts, mobile version, and social version separately. Do not combine them into one final image.
5. Keep names, event type, date, and call to action prominent; keep secondary details readable and logically grouped.
6. Proofread every repeated detail across the suite and resolve contradictions before delivery.
7. When a map or QR code is requested, use verified data and test the code/link before claiming it works.
8. When Canva tools are available, create the editable template. Otherwise provide separate assets and a Canva build guide without claiming an editable link.
9. Create one listing preview only after all individual files are complete.
10. Supply buyer instructions, print guidance, personalization fields, product title, description, and included-files list.

## Boundaries
This skill creates invitation cards and stationery. A separate interactive-invitation skill should be used for clickable 10-page experiences with navigation, RSVP buttons, maps, galleries, and animated envelope intros.

## Core operating rules

1. **Create original work.** Treat user-provided screenshots, marketplace links, and sample products as inspiration for mood, structure, palette, or product scope only. Never trace, reproduce, or closely imitate a third-party product, logo, copyrighted character, photograph, wording, or exact composition.
2. **Plan before generating.** Confirm or infer the audience, purpose, theme, palette, dimensions, number of assets, and delivery format. Then show a concise numbered manifest before creating the final assets.
3. **Use sensible defaults instead of delaying the project.** Ask only questions that materially change the result. When details are missing, state the assumptions and proceed with a polished default.
4. **Separate-asset rule.** Every final page, card, template, printable, or graphic must be generated and delivered as its own file/image. Do not place multiple final assets on one contact sheet. A collage is allowed only as a separate listing-preview image after the individual files are complete.
5. **Batch rule.** Generate no more than 10 final images in one batch. Label every asset and continue in numbered batches until the approved manifest is complete.
6. **Lock the visual system.** Keep the same palette, typography direction, border treatment, illustration style, spacing system, and recurring decorative elements across the complete collection.
7. **Prioritize usability.** Text must be readable, writing areas must be practical, important details must not be cut off, and decorative elements must not interfere with content.
8. **Respect requested dimensions.** Use the exact dimensions and orientation the user provides. When the user does not specify dimensions, use the defaults in this skill and state them before production.
9. **Proofread.** Check names, dates, prices, contact information, headings, spelling, page numbering, and repeated labels before final delivery.
10. **Package honestly.** Do not claim that a live Canva link, editable template, hyperlink, ZIP, PDF, or source file exists unless it was actually created. When requested, organize deliverables into clearly named folders and create the requested archive.
11. **Commercial-product finish.** When relevant, include a product title, listing description, feature list, buyer instructions, file manifest, suggested keywords, and at least one original listing-preview concept.
12. **Preserve approved work.** When the user requests a correction, make the targeted change without redesigning unrelated approved elements.

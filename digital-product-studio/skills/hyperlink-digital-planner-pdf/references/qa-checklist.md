# Hyperlinked Planner PDF QA Checklist

## Source

- [ ] Final page order confirmed
- [ ] Page count confirmed
- [ ] Dimensions and orientation confirmed
- [ ] No missing or duplicate pages
- [ ] Source copy preserved

## Links

- [ ] Real PDF annotations exist
- [ ] Every required tab is linked
- [ ] Every destination is within range
- [ ] Home links to the approved dashboard
- [ ] Previous and Next avoid invalid pages
- [ ] External URLs are exact
- [ ] Rectangles remain inside pages
- [ ] Rectangles have positive width and height
- [ ] Adjacent controls do not overlap ambiguously
- [ ] Repeated tabs appear on every specified page
- [ ] Active tabs follow the approved rule

## Visual preservation

- [ ] Page artwork is unchanged
- [ ] Page dimensions are unchanged
- [ ] No visible hyperlink borders appear
- [ ] No page was stretched or cropped
- [ ] Image quality remains acceptable
- [ ] Final PDF was rendered and visually inspected

## Reports

- [ ] Page inventory included
- [ ] Hyperlink map included
- [ ] Validation report included
- [ ] Annotation count reported
- [ ] Any limitations stated accurately

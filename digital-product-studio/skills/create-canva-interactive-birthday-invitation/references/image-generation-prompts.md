# Image-Generation Prompt Patterns

Replace bracketed fields with the user's information. Generate one section at a time.

## Master consistency line

Use this line in every section prompt:

> Match the approved master style exactly: [PALETTE], [MOTIFS], [LIGHTING], [BORDER STYLE], [TYPOGRAPHY DIRECTION], and [MATERIAL TREATMENT]. Keep the design spacious, polished, mobile-friendly, and not overcrowded. This must look like the same invitation website as all previously approved sections.

## Mandatory envelope opening prompts

Generate these before every other section.

### Image 1 — closed envelope

> Create the first image for an original interactive-style birthday invitation website that will be assembled in Canva. Show one complete closed [ENVELOPE STYLE] envelope as the main focus on a clean [BACKGROUND] background. Decorate it with [SEAL / BOW / RIBBON / FLORALS / MONOGRAM / THEMED DETAILS]. Match the approved palette and material style: [STYLE SYSTEM]. Final customer size: [WIDTH] × [HEIGHT] [UNIT], [ORIENTATION], [ASPECT RATIO]. Leave enough open space for a smooth Canva reveal transition. Do not show an opened flap or the invitation card. Do not create a collage, storyboard, phone mockup, browser frame, watermark, or multiple envelope states. This is the first visible image. Lock the envelope's exact position, size, angle, perspective, lighting, shadows, decoration placement, crop, and background for Image 2.

### Image 2 — opened envelope edit

> Edit the supplied approved closed-envelope image to create the second image in the invitation opening. Keep the same canvas and preserve the exact envelope position, size, angle, perspective, palette, materials, lighting, shadows, decoration placement, crop, and background. Change only the envelope state: open the flap and reveal an invitation card emerging from inside. The card may show [SHORT HEADING / NAME / MONOGRAM / AGE] with minimal matching decoration. Do not redesign, move, rotate, recolor, resize, recrop, or replace the envelope. Do not generate an unrelated second scene. The two images must align directly at identical coordinates in Canva so a short transition makes the envelope appear to open.

## Transparent asset prompt

> Create a coordinated transparent-background decorative asset pack for the approved [THEME] birthday invitation. Include [ASSET LIST]. Match the exact palette, lighting, materials, and illustration style of the approved invitation sections. No text, no background, no watermark, clean edges, separate well-spaced objects, and no duplicates.

## Two-phone listing mockup prompt

> Create a premium promotional mockup for an interactive birthday invitation website. Place two realistic modern smartphone mockups side by side and display the uploaded finished invitation screenshots inside the phones without altering, redrawing, cropping important text, or changing their proportions. Use a coordinated [THEME] birthday background with restrained matching decorations. Keep the phone screens large, centered, and readable. Do not cover the screens. Use the customer's requested listing-image size: [WIDTH] × [HEIGHT] [UNIT], [ORIENTATION], [ASPECT RATIO]. If the exact size is unsupported, preserve the requested aspect ratio for exact resizing in Canva.

## Correction prompt

> Revise only the uploaded [SECTION NAME]. Keep every approved element and the master style unchanged. Change only the following: [CORRECTIONS]. Preserve the canvas size, spacing rhythm, palette, typography direction, and all other artwork.

## Envelope continuity correction prompt

> Correct only the opened-envelope image using the approved closed-envelope image as the mandatory reference. Match the closed image's canvas, envelope position, scale, angle, perspective, background, lighting, shadows, palette, materials, and decoration placement exactly. Change only the flap from closed to open and reveal the invitation card. The two images must align at identical coordinates in Canva. Do not redesign or regenerate the scene.

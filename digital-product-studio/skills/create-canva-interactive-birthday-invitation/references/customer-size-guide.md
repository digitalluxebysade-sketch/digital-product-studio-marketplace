# Customer Size Guide

Use this guide whenever a customer requests a specific design size.

## Required size fields

Record these before generating the first invitation section:

- Width
- Height
- Unit: px, in, cm, or mm
- Orientation: portrait, landscape, or square
- Aspect ratio
- Final use or platform
- Same size for every section, or mixed-size bundle

## Size-first rule

The customer's stated dimensions take priority over the default. Keep all invitation sections at the approved size unless the customer explicitly asks for different sizes.

If the customer names only a platform or product, use its current Canva preset when confidently known. Otherwise, state the proposed dimensions before generation or use a clearly labeled placeholder size. Do not pretend an uncertain preset is exact.

## Unsupported exact generation dimensions

Image generation may not directly output every possible custom dimension. In that case:

1. Calculate or preserve the requested aspect ratio.
2. Generate at the closest supported dimensions with that ratio.
3. Keep essential content inside generous safe margins.
4. Create the exact custom-size canvas in Canva.
5. Scale proportionally. Never stretch.
6. Crop only expendable outer background areas.
7. Verify the exact Canva export dimensions before delivery.

## Common examples, not limits

- Mobile invitation: 1080 × 1920 px, 9:16
- Square listing image: 2000 × 2000 px or the customer's chosen square size
- Instagram portrait: 1080 × 1350 px, 4:5
- Printable invitation: 5 × 7 in
- Presentation: 16:9 or the customer's chosen dimensions
- Tablet page: any customer-requested portrait or landscape size

These are examples only. Never override a customer's explicit dimensions with a preset.

## Prompt language

Include this in every section prompt:

> Final customer size: [WIDTH] × [HEIGHT] [UNIT], [ORIENTATION], [ASPECT RATIO]. Compose specifically for this format. Keep essential text, buttons, and decorations inside generous safe margins. If exact generation dimensions are unavailable, preserve the aspect ratio and prepare the design for exact placement in Canva without stretching.

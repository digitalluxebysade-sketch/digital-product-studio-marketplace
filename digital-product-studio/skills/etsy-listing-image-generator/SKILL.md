# Etsy Listing Image Generator

## Purpose
Turn a digital product, finished product file, screenshots, mockups, branding, or written product description into a polished set of Etsy-ready listing images designed to explain the product clearly, showcase its value, and help shoppers understand what they receive.

This skill creates listing graphics only. It does not redesign the underlying product unless the user explicitly asks for that too.

## Non-Negotiable Production Rules

1. Use built-in image generation for every finished listing image.
2. Do not replace finished listing visuals with SVG, HTML, CSS, Python, Node, slide shapes, or code-built layouts.
3. Code may only be used after generation for simple file naming, resizing, packaging, format conversion, or ZIP assembly.
4. Every requested listing image must be generated as its own separate image file.
5. Do not combine the entire listing set into one contact sheet, collage, or preview unless the user separately requests a contact sheet.
6. A single listing image may contain several product mockups or screenshots when that is the purpose of the design.
7. Continue automatically in batches until the complete approved image count is finished. Do not stop after a sample.
8. Preserve approved work. When the user requests a correction, regenerate only the affected image unless the change must apply across the entire visual system.
9. Use the uploaded product files and reference images as visual guidance. Do not copy another seller's exact branding, wording, photographs, or protected artwork.
10. Do not invent ratings, review counts, sales numbers, earnings claims, platform badges, certifications, or product features.
11. Keep all product details accurate. Do not display pages, features, links, formats, devices, or bonuses that are not actually included.
12. Do not place a mascot, pixel character, or model in every image unless the user specifically requests that. The product remains the focus.

## Required Inputs

Use details already provided. Ask only for missing information that materially affects the final images.

Collect or infer:

- Product name
- Product type
- Target customer
- Exact number of listing images
- Requested dimensions or aspect ratio
- Product files, screenshots, covers, pages, or mockups
- Brand colors, fonts, theme, and visual references
- Exact features and contents
- File formats included
- Whether the product is editable, printable, hyperlinked, instant download, or compatible with specific apps/devices
- Any exact wording that must appear
- Whether a person, character, hand-held device, desk scene, or lifestyle mockup should appear

If the user gives no image count, default to 7 separate listing images.

If the user gives no size, default to a square 2000 × 2000 px canvas. Follow any user-provided dimensions exactly.

## Phase 1 — Product Audit

Before generating, inspect all supplied files and summarize the real product offer:

- What the product is
- Who it is for
- What files are included
- What the strongest selling points are
- Which pages or assets should be shown
- Which claims are safe and accurate
- Which product details need to remain readable

For multi-page files, select visually useful pages that show variety. Avoid repeatedly featuring the same cover or dashboard.

## Phase 2 — Locked Visual System

Create one consistent listing-image system before the first generation:

- Canvas size and aspect ratio
- Background style
- Color palette
- Heading style
- Supporting font direction
- Border, ribbon, badge, icon, floral, bow, lace, frame, sparkle, or decorative treatment
- Product mockup style
- Device-frame style when relevant
- Spacing and text hierarchy
- Repeating footer, shop name, watermark, or logo placement when supplied

The system must stay cohesive across the full set while allowing each image to have a different composition.

Do not make every image look identical. Vary the arrangement while keeping the same design language.

## Phase 3 — Numbered Listing Manifest

Create a numbered manifest matching the exact requested count. Confirm the count in the response, then continue through the full set.

### Default 7-Image Manifest

1. **Hero / Cover Image**  
   Product name, strongest promise, polished product mockups, and one clear feature callout.

2. **What Is Included**  
   Clear breakdown of the actual files, pages, sections, templates, or bonuses included.

3. **Product Preview**  
   Multiple real page previews or screens arranged cleanly so shoppers can understand the design.

4. **Key Features**  
   Showcase the strongest functional benefits, such as hyperlinks, editable text, trackable RSVP, printable sizes, navigation, or reusable templates.

5. **How It Works**  
   A simple visual sequence such as purchase → download → open/edit/use. Keep it specific to the product.

6. **Device / Format / Compatibility View**  
   Show accurate mobile, tablet, laptop, desktop, print, or app compatibility only when true.

7. **Final Value / Call-to-Action Image**  
   Summarize the outcome, ideal customer, delivery method, and an accurate purchase reminder.

### Optional Expanded 10-Image Manifest

When the user requests 8–10 images, add only relevant concepts such as:

- Close-up feature spotlight
- Before-and-after organization view
- Page-category overview
- Bonus files
- Personalization options
- Printing or sizing guide
- FAQ / important notes
- Gift or event-use example
- Shop bundle comparison
- Customer journey or use-case image

## Product-Specific Manifest Guidance

### Interactive Invitations
Prioritize:

- Hero phone mockup
- Envelope-opening screen
- Full mobile scroll preview
- RSVP feature
- Music button
- Google Maps or venue link
- Countdown or schedule
- Mobile and desktop views
- QR-code card or share method
- Page overview

Never imply that a live RSVP form, map, countdown, or music feature exists unless it is truly linked or supported in the delivered product.

### Digital Planners
Prioritize:

- Cover and dashboard
- Correct tabs and navigation
- Monthly, weekly, daily, finance, wellness, or specialty pages
- Hyperlinked navigation when included
- Tablet mockups
- Writing space and functional sections
- Page-count or section overview
- Compatibility and import instructions

Use the actual tab colors, ring style, page ratio, and layout from the finished planner. Do not invent pink tabs, extra rings, or features that are not present.

### Ebooks
Prioritize:

- Cover mockup
- Interior reading-page previews
- Chapter overview
- Main learning outcomes
- Device reading view
- File format and delivery
- Ideal reader

Treat an ebook as a book for reading unless the product is specifically a workbook. Do not present blank writing boxes, trackers, or interactive exercises unless they are actually included.

### Workbooks and Printables
Prioritize:

- Cover
- Worksheet previews
- Writing areas
- Printable sizes
- Page count
- Use cases
- Instant-download steps

### Automation Systems or Skill ZIPs
Prioritize:

- Hero showing the digital automation concept
- What the automation creates
- One-prompt workflow
- Customer download and installation flow
- What files are included in the ZIP
- Example outputs
- Who it is for
- Important requirements

Explain that the system performs the workflow after the customer installs it. Do not say it merely “helps create” when the automation is intended to complete the creation process.

## Layout and Design Standards

- Make the product the visual focus.
- Use a strong headline visible at thumbnail size.
- Use short, accurate supporting copy.
- Keep text readable and proofread.
- Do not overcrowd the image.
- Leave intentional negative space.
- Use realistic perspective and lighting on mockups.
- Keep device screens aligned and undistorted.
- Keep page previews sharp enough to show the real layout.
- Avoid tiny paragraphs. Convert long information into concise callouts.
- Use icons only when they improve comprehension.
- Maintain safe margins so important text is not cut off.
- Avoid placing critical wording over busy product previews.
- Use one dominant message per listing image.
- Use consistent visual hierarchy across the set.
- Keep decorative elements secondary to the product.

## Reference-Library Guidance

The bundled reference images show useful composition patterns, including:

- Large hero headline with layered phone mockups
- Gold or metallic feature badges
- Full-length mobile invitation previews
- Circular close-up callouts
- Feature icons for music, maps, time, gifts, and RSVP
- Physical card or QR-card mockups on fabric or styled surfaces

- Mobile page overview grids
- Soft floral, bow, butterfly, and luxury-event styling

Use these references for composition, hierarchy, mockup direction, and merchandising strategy. Adapt the design to the user's product and brand. Do not reuse names, dates, photographs, exact text, seller watermarks, or exact artwork from a reference.

## Generation Workflow

For each numbered listing image:

1. State the image number and purpose internally.
2. Use the locked visual system.
3. Use the real supplied product artwork wherever available.
4. Generate one complete listing graphic at the requested dimensions.
5. Check spelling, hierarchy, product accuracy, cropping, device alignment, and visual consistency.
6. Regenerate only when the image has a meaningful defect.
7. Save with a clear numbered filename.
8. Continue to the next image until the manifest is complete.

Recommended filenames:

- 01-hero.jpg
- 02-whats-included.jpg
- 03-product-preview.jpg
- 04-key-features.jpg
- 05-how-it-works.jpg
- 06-compatibility.jpg
- 07-final-value.jpg

## Quality-Control Checklist

Before delivery, verify:

- Exact requested image count is complete
- Every image is a separate file
- Correct dimensions
- Consistent visual identity
- Product name is spelled correctly
- No fake claims or invented features
- Text is readable at thumbnail size
- Important wording stays within safe margins
- Product screenshots match the supplied product
- No accidental duplicate compositions
- No repeated model or character unless requested
- No seller watermarks from references
- No distorted hands, devices, pages, bows, florals, or typography
- No missing image from the approved manifest

## Delivery

Deliver:

- All finished listing images as separate files
- A clearly numbered image manifest
- A ZIP containing the complete image set when requested
- Optional short Etsy listing title, description, and image alt text only when requested

Do not claim completion until every requested listing image has been generated and checked.

# Etsy Listing Image Generator

## Install
Upload the ZIP to ChatGPT Work and install the top-level `etsy-listing-image-generator` folder as a personal skill.

## Suggested installation message

Install the skill contained in this ZIP as a personal skill named **Etsy Listing Image Generator**. Preserve the complete `SKILL.md` file and bundled visual-reference library. The skill must use built-in image generation for each finished listing image, generate every requested image separately, and continue until the full approved listing set is complete.

## Quick start

Use a prompt such as:

> Start Etsy Listing Image Generator and create 7 separate Etsy-ready listing images for my digital product. Use the uploaded product file and brand references, create a numbered image manifest, keep the set cohesive, and generate every image separately at 2000 × 2000 px.

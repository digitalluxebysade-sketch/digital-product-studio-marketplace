# Digital Planner Studio by Sadé

Digital Planner Studio is a focused plugin for creating polished, functional digital planners. It includes only the core planner workflow: tab-shape selection, image-generated planner creation, and PDF hyperlinking.

## Image-generation-only creation policy

Every cover, master shell, interior page, divider, and correction must be created with image generation or image editing. Do not create planner visuals with code, HTML, CSS, JavaScript, Canva, spreadsheet layout, PDF drawing, or another non-image-generation method. PDF hyperlinking is a post-creation step: it may inspect, assemble, and annotate approved image-generated pages, but must not redraw or alter the visual artwork.

Use the three named specialist skills directly: choose a tab shape first, create the planner with image generation, then hyperlink the finished PDF when needed.

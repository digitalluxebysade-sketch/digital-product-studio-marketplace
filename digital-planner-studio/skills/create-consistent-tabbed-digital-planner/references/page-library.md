# Planner Page Library

Select only the pages needed for the project.

Every selected page must receive a unique title, purpose, and complete functional worksheet specification in the numbered manifest. A category name alone is not a finished page. Blank or lightly decorated note sheets may be supplied only as extras and do not count toward the requested functional page total unless the user explicitly includes them.

# Privacy Policy for Digital Product Studio by Sadé

**Effective date:** September 7, 2026

Digital Product Studio by Sadé is a skills-only plugin for ChatGPT and Codex. It provides instructions, templates, scripts, and bundled assets that help users create digital products.

## Information collected by the plugin developer

The plugin does not operate its own server, require a developer account, use API keys, include analytics or tracking, or send information to the plugin developer. The developer does not receive, collect, store, or sell users' prompts, uploaded files, generated files, account information, or usage data through the plugin.

## Processing by ChatGPT, Codex, and connected services

When a user runs the plugin, prompts, files, and generated content may be processed by ChatGPT, Codex, OpenAI, and any tools or third-party services the user chooses to connect. Those services process information under their own terms and privacy policies.

The plugin may instruct the host application to read files supplied by the user and create files in the user's workspace. The developer does not have access to those files through the plugin.

## Bundled assets

The plugin includes reference materials and other assets supplied with the plugin package. These bundled assets are part of the product and are not user data.

## Children's privacy

The plugin is not designed for or marketed to children under 13. It may help adult users create products intended for children, such as activity books or educational resources.

## Changes to this policy

This policy may be updated when the plugin's features or data practices change. Updates will be published in this repository with a revised effective date.

## Contact

Privacy questions can be submitted through the repository's [GitHub Issues page](https://github.com/digitalluxebysade-sketch/digital-product-studio-marketplace/issues). Do not include confidential or sensitive personal information in a public issue.
